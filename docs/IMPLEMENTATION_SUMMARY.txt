1️⃣  BACKTESTING AUTOMATIZADO
    ├─ ✅ Validación histórica de predicciones
    ├─ ✅ Métricas: accuracy, precision, recall, F1-score
    ├─ ✅ Matrices de confusión
    ├─ ✅ Análisis por modelo individual
    ├─ ✅ Análisis de ensemble (votación)
    ├─ ✅ Reportes JSON exportables
    └─ ✅ Accuracy ponderada por confianza

2️⃣  INDICADORES TÉCNICOS AVANZADOS
    ├─ ✅ MACD (línea, señal, histograma)
    ├─ ✅ Bollinger Bands (3 bandas + %B + ancho)
    ├─ ✅ ADX (+DI, -DI) - Fuerza de tendencia
    ├─ ✅ ATR - Volatilidad real
    ├─ ✅ Stochastic Oscillator (%K, %D)
    ├─ ✅ OBV - On-Balance Volume
    ├─ ✅ EMAs (12, 26, 200)
    └─ ✅ Tabla PostgreSQL 'advanced_indicators'

3️⃣  DASHBOARD STREAMLIT INTERACTIVO
    ├─ Tab 1: Precio & Predicciones
    │   ├─ ✅ Gráfico candlestick
    │   ├─ ✅ Predicciones superpuestas
    │   ├─ ✅ Volumen
    │   └─ ✅ Métricas en tiempo real
    ├─ Tab 2: Indicadores Técnicos
    │   ├─ ✅ Bollinger Bands sobre precio
    │   ├─ ✅ MACD con histograma
    │   ├─ ✅ Stochastic con niveles
    │   └─ ✅ ADX con direccionalidad
    ├─ Tab 3: Backtesting
    │   ├─ ✅ Ejecución con un click
    │   ├─ ✅ Gráfico comparativo
    │   ├─ ✅ Tabla de métricas
    │   └─ ✅ Comparación ensemble vs individual
    └─ Tab 4: Heatmap (preparado)

      compute_advanced_indicators_for_symbol('^IBEX')"

    $ streamlit run scripts/ui/streamlit_dashboard.py
    # Abrir http://localhost:8501

    # 4. (Opcional) Iniciar Bot

    $ python3 scripts/ui/telegram_bot.py
