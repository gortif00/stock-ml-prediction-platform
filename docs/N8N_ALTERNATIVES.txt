For your project → Use APScheduler ⭐

Why?
✅ Simpler setup (no Docker needed)
✅ Lighter weight (50MB vs 500MB)
✅ Pure Python (easy to understand and debug)
✅ Perfect for daily data updates
✅ All code in one file (scripts/automation/scheduler.py)
✅ Easy to demonstrate in academic presentation

When to use n8n instead:
- Need visual workflow builder
- Non-technical users need to configure
- Complex branching logic
- Multiple external integrations (email, Slack, webhooks)

💡 OTHER ALTERNATIVES (if you want)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Cron Jobs (Linux/Mac)
   Pro: System-level, very reliable
   Con: Less flexible, OS-specific

2. Celery + Redis
   Pro: Distributed, scalable
   Con: Overkill for your use case, complex setup

3. Apache Airflow
   Pro: Enterprise-grade, visual DAG
   Con: Heavy, complex, overkill

4. GitHub Actions (if code is on GitHub)
   Pro: Free, cloud-based
   Con: Requires push to trigger, limited schedule options

5. AWS Lambda / Cloud Functions
   Pro: Serverless, scalable
   Con: Requires cloud account, costs money

6. Task Scheduler (Windows) / systemd (Linux)
   Pro: OS-native
   Con: Platform-specific

Want to change schedule? Edit scripts/automation/scheduler.py:

# Example: Change fetch data time to 7:00 AM
scheduler.add_job(
    task_fetch_data,
    CronTrigger(hour=7, minute=0),  # Changed from 8 to 7
    id='fetch_data',
    name='Fetch Market Data'
)

# Example: Run predictions every 4 hours
scheduler.add_job(
    task_ml_predictions,
    CronTrigger(hour='*/4'),  # Every 4 hours
    id='ml_predictions'
)
